# GA4-Funnel-analysis
Funnel analysis of conversion based on GA4 data
 GA4 Funnel & Channel Analysis

Аналитический pet-проект: разбор данных GA4 (экспорт в BigQuery) — воронка покупок и эффективность каналов трафика. 
Цель — потренировать SQL (CTE, оконные функции, подзапросы) на реальной структуре данных GA4 и получить прикладные бизнес-инсайты.

 Стек

- BigQuery — хранение и обработка данных (GA4 export schema)
- SQL — CTE, оконные функции (`LAG`, `ROW_NUMBER`, `PARTITION BY`), подзапросы (`IN`/`EXISTS`/скалярные), `JOIN`, `GROUP BY`

 Структура репозитория

```
├── queries/
│   ├── funnel.sql        воронка: view_item → add_to_cart → ... → add_payment_info
│   ├── channels.sql      разрез по каналам: viewers, payers, conversion_pct
│   └── ...
└── README.md
```

 Что считает `funnel.sql`

Строит воронку по шагам событий GA4 и считает конверсию между соседними шагами (оконная функция `LAG` для сравнения с предыдущим шагом).

- view_item — 61 252 пользователей (старт воронки)
- add_to_cart — 12 545 (конверсия от предыдущего шага: 20.5%)
- begin_checkout — 9 715 (77.4%)
- add_shipping_info — 9 714 (100.0%)
- add_payment_info — 5 751 (59.2%)

Главный инсайт: самая узкая часть воронки — переход от просмотра товара к добавлению в корзину (только 20.5% доходят дальше). Второй проблемный участок — от заполнения данных доставки до оплаты (59.2%), это точка, где чаще всего теряют платящих пользователей.

 Что считает `channels.sql`

Разрез пользователей по каналам привлечения: объём (viewers), платящие (payers) и конверсия в оплату.

- organic — 21 652 viewers, 1 631 payers, конверсия 7.5%
- referral — 17 580 viewers, 2 903 payers, конверсия 16.5%
- none — 10 783 viewers, 529 payers, конверсия 4.9%
- Other — 8 184 viewers, 449 payers, конверсия 5.5%
- cpc — 2 504 viewers, 136 payers, конверсия 5.4%
- data_deleted — 549 viewers, 60 payers, конверсия 10.9%

Главный инсайт: referral — не самый крупный канал по объёму (второй после organic), но заметно опережает все остальные по качеству трафика: конверсия 16.5% против 7.5% у organic. Это сигнал к перераспределению бюджета/усилий в сторону referral-каналов, а не только к масштабированию самого большого канала.

 Как запустить

1. Открыть BigQuery console (или через `bq` CLI).
2. Выполнить запросы из `queries/` на своём GA4-датасете (замените `project.dataset.events_*` на свою таблицу).
3. Результаты можно выгрузить в CSV и визуализировать (например, в Power BI — построена связанная воронка + дашборд по каналам).
